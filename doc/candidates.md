# 候補（Candidates）

ビートごとに複数の「見た目（ルック）」を候補として保持し、比較して選べる機能です。
左ペインの「候補」タブから操作します。

## 候補タブ

- **生成**: 選択中のビートに対する候補を新しく作ります。ビート自体は変わりません（候補リストが増えるだけ・1回の取り消しで戻せます）。
  - 生成モード: 混ぜる / 近い / 別物。
  - 生成数: ×4 / ×6 / ×9 / ×12。
- **現在を保存**: いまビートに付いている見た目を、そのまま候補として残します。
- カード右上の **★** は固定（押し出されない）、**×** は削除です。

## ホバーとクリック

- カードに**カーソルを重ねる**と、その見た目がビートに一時的に当たり、再生しながら確認できます。
  プレビュー中は履歴に残りません（トランザクションで適用し、カーソルが外れると巻き戻します）。
- カードを**クリック**すると、その見た目をビートに確定適用します（取り消し1回分）。

## 元の状態（Original）

最初に生成したときの見た目は候補0番として自動的に記録されます。何度でも選び直せますが、削除はできません。
手作業で整えた見た目は、別の候補を当てる直前に「直前」候補として自動保存されるため、失われません。

## 変更する要素（軸）

生成時、どの部分を変えるかをチップで絞り込めます。選ばなかった部分は現在の見た目からコピーされます。

- **色**: ビートごとのパレットを候補ごとに別のものへ切り替えます。テキストの色は個別に塗らず、パレットから決まります。ビートの区間にある背景・フィラー・図形クリップ（パレットに追従するもの）も同じパレットで塗り替わり、「元の状態」を選べば戻ります（`palette` / `paletteIndex` / `paletteInvert` / `colorScheme` / `colorLegacy`）
- **書体**: `text.fontId` / `text.weight`
- **効果**: enter / exit / hold / animation / fill / edge / post / repeat
- **配置**: `text.align` / `maxWidth` / `letterSpacing` / `lineHeight` と layout / location
- **クローン**: 同じ文字列を並行して複製する `clones`。オンなら、3つに1つの候補にクローンを付けます。オフなら付けず、現在のクローン設定はそのまま残ります。

既定はすべてオン（従来どおり全要素が変わります）。

## 合成（Mix）

「合成」ボタンでインライン編集を開きます。

1. **ベース**となる候補を選ぶ。
2. 軸ごとに「取得元の候補」を選ぶ（未指定ならベースのまま）。
3. 「合成を適用」で、選んだ軸だけを取得元から取り込んだ新しい候補を保存して適用します。

例: 色を B から、効果を C から、それ以外は A から、という組み合わせが作れます。

## ボードペイン

「ボード」ボタンで、タイムラインの下に**ボードペイン**が開きます（ダイアログではなく常設のペインです。ペイン見出しの × で閉じます）。

- 横軸 = 曲順のビート、縦軸 = 候補の番号。曲全体をもう一つの候補用タイムラインとして見渡せます。
- 列見出し（ビートの抜粋・時刻・候補数・「生成」ボタン）は上端に、行番号は左端に固定されます。上下左右にスクロールできます。
- 各マスはサムネイルで、いまビートに付いている候補（見た目が一致するもの）は強調表示されます。マスをクリックするとその候補をそのビートに適用します（取り消し1回分）。
- マスにホバーすると、候補タブと同じく、そのビートへ候補を一時適用して再生プレビューします（離すと元に戻り、再生位置も戻ります）。ホバー中はボードを再描画せず、追従スクロールも止めます。クリックで確定します。
- 候補のないビートは、ペインを開いたときに自動で「元の状態」が候補0番として作られます（ランダム候補は作りません）。生成設定（モード / 数 / 軸）は候補タブと共通です。
- プレビュー再生中は、再生ヘッドのある列が `is-now`（見出しの強調と縦のマーカー）になり、必要に応じて横スクロールで追従します。手でスクロールすると次の再生まで追従を止めます。
- サムネイルは表示中のマスだけ、順番に、候補タブと同じ仕組み（トランザクションで適用→`captureRGBA`→巻き戻し）で描画し、履歴には残りません。再生中やホバー / 連続再生のトランザクション中は描画しません。

## メモリ

候補はプロジェクトに保存されますが、増えても破綻しないように作られています。

- ルック1つはおおむね 0.3〜2 KB です。ビート1600個ぶんの候補でもファイルも RAM も数 MB 程度です。
- ビートの区間にある背景・フィラー・図形クリップのスナップショットは、ルックごとに重複して持たず `candidatePool` にハッシュ（FNV-1a）で一度だけ保存し、ルックはハッシュだけを参照します。同じクリップを使う複数のルックは1つのスナップショットを共有します。参照されなくなったスナップショットは削除時に自動で掃除されます。
- 候補リスト（生成 / 削除 / 固定 / 保存）は**取り消し履歴のスナップショットに含めません**。取り消し1回分がプロジェクトを丸ごと2部持つのを避けるためで、履歴には見た目を変える「適用」だけが残ります。候補の変更は履歴を作らずにプロジェクトを「未保存」にします。
- サムネイルはメモリ上の上限付きキャッシュ（600件・古い順に破棄）にのみ存在し、プロジェクトには保存されません。
- ボードのマス目は DOM 上に可視範囲ぶんだけ生成します（バーチャル化）。500ビート×24候補でも軽快に動きます。

## 連続再生

「▶ 連続再生」で、そのビートを繰り返し再生しながら、**ビートが終わった瞬間に次の候補へ切り替え**ます（待ち時間や巻き戻しの隙間はありません）。
全候補を一周したら最初に戻って続けます。切り替えは一時的なプレビューで、履歴には残りません。
ホバー・クリック・生成・「■ 停止」で終了し、ビートは再生前の見た目に戻ります。カードをクリックするとその候補が確定します。

## 上限と再生成

- 1 ビートあたりの候補は**最大 15 個**です。
- 「生成」を押すと、**使用中の候補・「元の状態」・★固定したもの以外は削除**してから、新しい候補を作ります。残った数を引いた分（15 − 残数）までしか作れません（足りないときは通知します）。

## ボードペインのヘッダ

- **＋ 候補を生成**: 選択中（なければ再生位置）のビートに、候補を生成します。
- **全ビートに生成**: 曲の全ビートを順に再生成します（確認あり、1 ビートあたり最大 6 個）。押し直すと中断します。
- モード（混ぜる／近い／別物）と個数、変える要素（軸）は、候補タブと共通です。

## ペインの開閉

- タイムラインとボードペインは、タイトルバーの「▾」で閉じられます。
- 閉じたペインは、画面下端の細いバー（「▴ タイムライン」「▴ ボードペイン」）から開き直せます。
- 開閉と高さはレイアウトとして保存されます。
