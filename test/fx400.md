# FX 400 代表効果一覧

`test/fx400.telopmotion.json` のキュー n に、この表の n 番の効果を適用しています。
効果は `scripts/fx400.js` が効果レジストリから決定的に生成したもので、`test/fx400.catalog.json` に完全なレシピを記録しています。

| コマンド | 内容 |
|---|---|
| `node scripts/fx400.js build` | カタログとプロジェクトを再生成 |
| `node scripts/fx400.js show 42` | 42番の効果の定義を表示 |
| `node scripts/fx400.js apply 42 --project <file> --cue 12 --out <file>` | 42番を既存プロジェクトのキュー12へ適用 |
