# 図形モーション見本 (figure showcase)

`figures.MOTIFS` の 69 個の Motif と、図形クリップが持つモーション軸（登場 / 保持 / 退場 / 同期 / 2D カメラ / 手続きモーション）を 1 キューずつ並べた見本プロジェクトです。

- 1 Motif = 1 キュー（3 秒）、モーション軸 = 1 キュー（4 秒）
- 図形は図形トラック（`fig`）のクリップです。キューは下部のラベルだけを持ちます
- モーション軸のセクションは参照 Motif `burst` を使い、隣り合うキューで違うのは見ている軸だけです
- シミュレーションの Motif（`reactionDiffusion` / `wave2d` / `fluid` / `cellular`）は *Settings → 状態をもつ演出を使う* のゲートに掛かっています。既定ではオフですが、Studio からこの見本を開くとゲートがそのセッションだけオンになります（保存された設定は変わりません）
- 開くには Studio の *Help → 図形見本*、または *File → Open project…* を使います
