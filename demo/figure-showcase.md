# 図形モーション見本 (figure showcase)

`figures.MOTIFS` の 64 個の Motif と、図形クリップが持つモーション軸（登場 / 保持 / 退場 / 同期 / 2D カメラ / 手続きモーション）を 1 キューずつ並べた見本プロジェクトです。

- 1 Motif = 1 キュー（3 秒）、モーション軸 = 1 キュー（4 秒）
- 図形は図形トラック（`fig`）のクリップです。キューは下部のラベルだけを持ちます
- モーション軸のセクションは参照 Motif `burst` を使い、隣り合うキューで違うのは見ている軸だけです
- 開くには Studio の *Help → 図形見本*、または *File → Open project…* を使います

| # | セクション | キュー数 | 時間 |
|---:|---|---:|---|
| 1 | 基本図形 (base) | 20 | 0–60s |
| 2 | 太線リズム (bold) | 6 | 60–78s |
| 3 | 手続き型 (proc) | 1 | 78–81s |
| 4 | 疑似3D (scene) | 11 | 81–114s |
| 5 | 幾何・データ構造 (geo) | 10 | 114–144s |
| 6 | 数式フィールド (field) | 16 | 144–192s |
| 7 | 登場 (in) | 4 | 192–208s |
| 8 | 保持 (hold) | 4 | 208–224s |

| | **合計** | **103** | **348s** |

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run figure-showcase -- build` | このプロジェクトとこの一覧を再生成 |
| `node scripts/figure-showcase.js list` | セクションとキューを一覧 |
| `node scripts/figure-showcase.js list --section camera` | 1 セクションだけ表示 |
| `npm run figure-showcase -- build --sections base,field` | Motif 家族を絞って生成 |
