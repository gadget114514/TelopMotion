# クローン見本 (clone showcase)

同じ文字列を3つ平行に描くクローン（`style.clones`）を 1 キューずつ並べた見本プロジェクトです。どのキューも同じ見本分を3コピー（dx -0.14 / 0 / +0.14）で描き、違うのは見比べる軸だけです。

- 1 キュー＝4 秒。コピーはインスペクターの語彙そのまま（dx / dy / scale / rotate / opacity / hue / delay / motion）です
- 動きのセクションは3コピーに同じ動きを付け、種類だけを変えた6キューです
- 色相は無彩色だと回転が分からないため、本体に有彩色を使っています
- 開くには Studio の *Help → クローン見本*、または *File → Open project…* を使います

| # | セクション | キュー数 | 時間 |
|---:|---|---:|---|
| 1 | ずらし (offset) | 4 | 0–16s |
| 2 | 大きさ (scale) | 1 | 16–20s |
| 3 | 回転 (rotate) | 1 | 20–24s |
| 4 | 不透明度 (opacity) | 1 | 24–28s |
| 5 | 色相 (hue) | 1 | 28–32s |
| 6 | 遅延 (delay) | 1 | 32–36s |
| 7 | 動き (motion) | 6 | 36–60s |
| | **合計** | **15** | **60s** |

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run clone-showcase -- build` | このプロジェクトとこの一覧を再生成 |
| `node scripts/clone-showcase.js list` | セクションとキューを一覧 |
| `node scripts/clone-showcase.js list --section motion` | 1 セクションだけ表示 |
| `npm run clone-showcase -- build --sections offset,scale` | セクションを絞って生成 |

## 1. ずらし (offset) (offset)

同じ文字列を横（dx）・縦（dy）にずらして3つ並べます。他はすべて同じで、違うのは位置だけです。dy+scale は縦ずらし＋大きさ、dy+fx は縦ずらし＋グロー（テキストエフェクト）の組み合わせです。

| # | キュー | 時間 | 値 | 内容 |
|---:|---|---|---|---|
| 1 | `cl_001` | 0–4s | `dx` | X -0.14 / 0 / +0.14 |
| 2 | `cl_002` | 4–8s | `dy` | Y -0.12 / 0 / +0.12 |
| 3 | `cl_003` | 8–12s | `dy+scale` | Y -0.12 / 0 / +0.12 · 0.75 / 1 / 1.25 |
| 4 | `cl_004` | 12–16s | `dy+fx` | Y -0.12 / 0 / +0.12 + glow |
