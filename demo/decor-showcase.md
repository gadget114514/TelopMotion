# 装飾見本 (decor showcase)

吹き出し・ラベル・囲み・チャットの装飾だけを 1 キューずつ並べた見本プロジェクトです。文字飾りと囲みフレームのキューは同じ見本分を表示し、違うのは装飾だけです。

- 文字飾り・ふきだし・抜き・飾りの動き・縁・囲みフレームは1種類＝1キュー（3 秒/キュー）、紙面は1種類＝1キュー（4 秒/キュー）
- 飾りの動き・縁のセクションは参照の飾り（rounded）を使い、隣り合うキューで違うのは動き・縁だけです
- 紙面の全 19 種はメインの Showcase にあります。ここでは装飾の文脈で使う 4 種（チャット・カード・メニュー）だけを抜粋します
- 開くには Studio の *Help → 装飾見本*、または *File → Open project…* を使います

| # | セクション | キュー数 | 時間 |
|---:|---|---:|---|
| 1 | 文字飾り (ornShape) | 18 | 0–54s |
| 2 | ふきだし (bubble) | 16 | 54–102s |
| 3 | 抜き・線だけ (stroke) | 8 | 102–126s |
| 4 | 飾りの動き (ornMotion) | 13 | 126–165s |
| 5 | 飾りの縁 (ornEdge) | 9 | 165–192s |
| 6 | 囲みフレーム (shapeLayer) | 17 | 192–243s |
| 7 | チャット・カード (page) | 4 | 243–259s |
| | **合計** | **85** | **259s** |

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run decor-showcase -- build` | このプロジェクトとこの一覧を再生成 |
| `node scripts/decor-showcase.js list` | セクションとキューを一覧 |
| `node scripts/decor-showcase.js list --section frame` | 1 セクションだけ表示 |
| `npm run decor-showcase -- build --sections orn,motion` | セクションを絞って生成 |
